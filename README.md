Shell Script Exercises with Description and Purpose (Part 2)
------------------------------------------------------------

Q1) Fibonacci Sequence
Description: Prints the first 10 numbers of the Fibonacci sequence.
Purpose: Demonstrates use of variables, arithmetic operations, and for loop in bash scripting.

Q2) Factorial of a Number
Description: Calculates the factorial of the number 5 using a for loop.
Purpose: Reinforces loop-based multiplication and factorial logic in bash.

Q3) Multiples of 3 Between 1 and 50

i) Using While Loop
Description: Prints all multiples of 3 from 3 to 50 using a while loop.
Purpose: Practice with while loop and step-wise incrementing.

ii) Using For Loop
Description: Prints multiples of 3 from 3 to 50 using a for loop with an increment of 3.
Purpose: Shows how to use step increments in a bash for loop.
