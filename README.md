✅ Q1: Print "Hello World!"
Explanation:

This program simply prints the message "Hello World!" to the console. It demonstrates the basic structure of a C program using #include and main().

✅ Q2: Display Age
Explanation:

The program defines an integer variable age, assigns it a value, and displays it using the %d format specifier.

✅ Q3: Assign New Value to Variable
Explanation:

The program prints the original value of age, changes it to a new value (31), and prints the updated result.

✅ Q4: Assign One Value to Two Variables
Explanation:
Demonstrates assigning the value of one variable (firstNumber) to another (secondNumber), showing how variables can be copied.

✅ Q5: Declare Multiple Variables in One Line
Explanation:
Illustrates how to declare multiple variables in a single line. Note: firstNumber is declared but not initialized, so it may print garbage value.

✅ Q6: Get the Size of a Number
Explanation:
Uses the sizeof() operator to determine the memory size (in bytes) of an integer variable.

✅ Q7: Initialize Double Number
Explanation:
Declares a double and prints it with two decimal places using %.2lf.

✅ Q8: Initialize Float Number
Explanation:
Declares a float variable and shows output with default and one decimal precision using %f and %.1f.

✅ Q9: Initialize a Character
Explanation:
Stores a character and prints both the character (%c) and its ASCII value (%d).

✅ Q10: Take Input from User
Explanation:
Prompts the user to enter their age and prints it using scanf() for input.

✅ Q12: Take Double and Character Input
Explanation:
Demonstrates how to get a double and a char input from the user in one line.
Note: Your older version had an issue with scanf("%1f %c",...) which should be corrected to scanf("%lf %c",...).

✅ Q13: Calculator
Explanation:
A simple calculator that performs addition, subtraction, multiplication, or division based on user input. It uses a switch statement for logic branching and checks for division by zero.
