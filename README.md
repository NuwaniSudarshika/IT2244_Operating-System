Shell Script Exercises with Description and Purpose
---------------------------------------------------

Q1) Astrology Based on Life Path Number
Description: This script asks the user for their date of birth and calculates a life path number.
Purpose: Demonstrates arithmetic operations and switch-case usage in bash scripting.

Q2) Summation and Multiplication of Numbers
Description: Takes a list of numbers from the user and calculates their sum and product using a for loop.
Purpose: Shows usage of arrays and iteration in shell scripting.

Q3) Print Integers from 1 to 10 using While Loop
Description: Uses a while loop to print numbers from 1 to 10.
Purpose: Practice with loop control structures in bash.

Q4) Pattern Printing using Nested Loops

i) Left-Aligned Triangle of Stars
Description: Prints increasing number of stars in each line up to a given number of rows.
Purpose: Practice nested loops for pattern printing.

ii) Inverted Triangle of Stars
Description: Prints decreasing number of stars in each line starting from the given number of rows.
Purpose: Practice reverse looping for pattern printing.

iii) Left-Aligned Triangle of Incrementing Numbers
Description: Prints numbers in increasing sequence on each line.
Purpose: Combines numeric logic with nested loops.

iv) Repeated Numbers in Triangle Pattern
Description: Prints each number repeatedly on its corresponding line.
Purpose: Combines iteration and variable referencing.

v) Center-Aligned Pyramid Pattern of Stars
Description: Prints a centered pyramid of stars using nested loops and spacing.
Purpose: Demonstrates complex pattern alignment using bash.

vi) Inverted Pyramid Pattern of Stars
Description: Prints a decreasing inverted triangle of stars aligned to the left.
Purpose: Practice decremental nested loops and formatted output.
