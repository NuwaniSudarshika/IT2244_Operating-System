✅ Q1 (Ternary): Voting Eligibility Using Ternary Operator
A simplified version of the voting eligibility program using a ternary (? :) operator instead of an if-else statement for compactness.

✅ Q2: Day of the Week Using switch-case
The user enters a number between 1 and 7, and the program uses a switch-case to print the corresponding weekday (Sunday to Saturday). If the number is outside the range, it prints an error.

✅ Q3: Astrology with Life Path Number
This program calculates a simple life path number by summing the digits of a user's birth date and uses a switch statement to display an astrology-related message based on the result.

✅ Q4: Fibonacci Series Generator
Generates a Fibonacci sequence up to a given number of terms using a for loop. It starts with 0 and 1, then calculates the next terms by summing the previous two.

✅ Q5: Factorial Calculator
Calculates the factorial of a given number using a for loop. The factorial is the product of all positive integers less than or equal to the number.

✅ Q6: Print 1 to 10 Using while Loop
Uses a while loop to print integers from 1 to 10 in sequence. It demonstrates basic loop usage in C.

✅ Q7: Sum and Product of a List
This program accepts a list of integers from the user and calculates both the sum and the product of those numbers using a for loop.

✅ Q8: String Concatenation
Accepts two strings from the user and concatenates them using the strcpy() and strcat() functions from the string.h library. The result is displayed.

✅ Q9: Binary to Decimal Converter
Converts a binary number (entered as an integer) into its decimal equivalent. The program also validates the input to ensure only binary digits (0 and 1) are used.

✅ Q10: Maximum and Minimum in an Array
Takes a list of integers from the user and finds the maximum and minimum values using a loop. It shows basic array traversal and conditional checking.

✅ Q11: Pascal's Triangle Generator
Generates Pascal’s Triangle up to the number of rows specified by the user. It uses a combination formula nCr = n! / (r!(n-r)!) and displays the triangle in a formatted way.
